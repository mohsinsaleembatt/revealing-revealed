# Lesson content

Original lessons for Revealing Revealed, written as YAML files and loaded into
the database by `data/import/import_lessons.py`.

- Licence: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0), once the
  source licences have been confirmed to allow it.
- Every lesson starts as `draft`. A lesson may only be marked `reviewed` or
  `approved` if every text block names a source, and a qualified reviewer has
  checked it.
- Qur'anic verses are never copied into these files. Use a reference such as
  `ref: "2:255"`; the text comes from the verified database.
